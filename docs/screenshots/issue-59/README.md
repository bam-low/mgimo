## Прочтение доказательств

После: горизонтальных переполнений 0, пересечений header actions с greeting/heading 0. До: пересечение на1280px в пяти состояниях главной. Это геометрическая проверка двух прямоугольников, не полная автоматическая визуальная или WCAG-приёмка.

Состояния дня снимались из реального защищённого API с управляемым временем ответа в Playwright, без записи в БД и изменения server clock. Пустой день — явно обозначенная UI fixture. Реальные права/пустые даты/отмена и live переходы дополнительно проверяются E2E. Не все состояния на всех четырёх ширинах: точная матрица в CSV. Пароли/токены/cookies/реальные документы не включены.
