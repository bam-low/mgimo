# Реальный интерфейс Issue #41

Playwright Chromium, локальный production standalone, только вымышленные записи. Это реальные снимки работающих UI/API/БД, без генерации изображений или screenshot-only стилей. Внешний вид на физических устройствах, клавиатуры/safe-area и полный WCAG/screenreader остаются для ручной приёмки; эмуляция Chromium не заменяет их. Production NO-GO сохраняется.
