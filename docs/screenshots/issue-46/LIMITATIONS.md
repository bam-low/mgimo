# Ограничения и вопросы ручного ревью

[Галерея](README.md)

- Три сохранённых Figma-экспорта доступны, актуальная онлайн-ревизия — нет (CONNECT 403). Если макеты изменены после передачи этих PNG, различия нужно сверить по новой версии. Pixel-perfect не заявляется.
- Это новая выборка основных страниц и существенных состояний. Все состояния предыдущей галереи PR #45 не пересняты; тамошние 118 PNG показывают прежний дизайн. Матрица новой версии содержит точное покрытие без заявления о каждом состоянии на каждой ширине.
- Native file picker, Save As, JavaScript confirm и PDF viewer находятся вне canvas страницы. Их окно не подменено нарисованным модальным макетом. Сценарии загрузки/скачивания и версий проверены E2E по действительным байтам.
- Только Chromium, CSS viewport и 100% при съёмке; системная клавиатура/реальные iOS/Android/Safari и полноценный screen-reader/WCAG-аудит требуют отдельной проверки. В регрессии сохраняется существующая проверка 200% reflow.
- Уведомления этапа 7 и другие функции, нарисованные только на Figma, не реализованы. Предлагаемые новые интерфейсы для них не входят в этот PR.
- Старый риск общего бюджета sign-in тестового набора остаётся: в одном локальном повторе schedule-states получил сообщение лимита входа и остался на /login; последний полный прогон 16/16 прошёл. Успех не означает устранение зависимости от окон лимита. Auth-лимиты и сценарии sign-in не менялись по ограничению владельца; [исходная диагностика](https://github.com/bam-low/mgimo/pull/45).

Владелец ещё не утвердил визуальный результат. Merge/deploy/production-приёмка не выполнены.
