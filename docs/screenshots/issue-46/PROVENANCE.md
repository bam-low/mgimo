# Происхождение снимков новой версии

Исходный main `f375bee1e329f61200bbafebf34c80bed805c8b1`; приложение реально изменено в `feat/figma-visual-alignment` для Issue #46. Это снимки новой работающей версии, не старый аудит и не статические HTML-макеты.

Настоящий production Next.js/Node 24.22.1, PostgreSQL, Chromium, ru-RU/Europe/Moscow. Съёмка 13.11.2026. Внешние тестовые часы процесса/браузера задают 16.11.2026, 09:30 по Москве: текущая пара показывается по реальному расписанию, без замены API. Данные той же изолированной `campus_audit65_test`, что и в исходном аудите PR #45: seed, разрешённые защищённые операции и вымышленные fixtures. Съёмка не редактирует учебные записи. Функциональные проверки выполнялись на отдельных чистых *_test БД.

Три Figma-референса — реальные owner PNG в [inventory](../../design/ASSET_INVENTORY_V3.md), полученные ранее из того же файла. Прямая онлайн-проверка файла 13.11 вернула CONNECT 403; текущая онлайн-ревизия неизвестна. Сравнения «до» извлечены из коммита материалов `79159cfb622ae226566847b0f75bdcbc097fa8db` PR #45; это работающая main до нового дизайна. Сравнения и миниатюры только пропорционально уменьшены Pillow, не ретушированы.

Обычный viewport имеет высоту 900 CSS px, ширины 360/390/768/1280, scale 100%, deviceScaleFactor 1. `full-page` — настоящий browser fullPage. `full-scroll-stitched` — явно обозначенная механическая склейка реальной внутренней прокрутки `.workspace-scroll` без CSS/DOM-изменений; закреплённая навигация показана на viewport. Формат и SHA256 каждого PNG — в [manifest](manifest.json).

Ни Figma full-screen PNG, ни screenshot-only CSS в runtime не используются. Сохраняются исходные локальные SVG и шрифты с provenance; новая document-иконка — собственная простая SVG-геометрия. Новый formatter использовался только из временного npm-cache, зависимости/lockfile проекта не изменены.

Пароли, env, cookies, HAR, дампы и выданные при регистрации реквизиты в комплект не входят. На снимках нет заполненных паролей; документы только вымышленные маркированные образцы. Ни deploy, ни merge не выполнялись, Production NO-GO сохраняется.
