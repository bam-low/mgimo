# Демонстрация — 4 минуты 30 секунд

Подготовка: две отдельные настоящие сессии STUDENT/STAFF в приватных окнах, только вымышленные имена и документы, никаких экранов с паролями/секретами. Пройти репетицию на том же baseline/принятых исправлениях. Не выдавать справку за настоящий документ. При отсутствии разрешённого стенда показать локально запущенное приложение/запись реального сценария; соответствие конкурсному требованию URL уточнить отдельно.

| Время | Роль и действие | Что показать |
| --- | --- | --- |
| 0:00–0:25 | Вступление | Кампус: единый учебный кабинет, две роли, вымышленные данные |
| 0:25–1:05 | STUDENT→STAFF | Выбор группы/ожидание; сотрудник подтверждает; уведомление и доступ к кабинету |
| 1:05–1:45 | STUDENT | Сегодня/неделя, несколько занятий, текущая пара с живым прогрессом при подходящем времени; оценка и история |
| 1:45–2:45 | STUDENT→STAFF | Заказ справки; TAKE; реальная загрузка образца; COMPLETE, ранее без файла невозможно |
| 2:45–3:20 | STUDENT | Уведомление/счётчик, прочтение, переход к заявке, ответ/история, защищённое скачивание |
| 3:20–3:55 | STAFF | Коротко направление/группа, A/B и общая лекция, серверный конфликт; исправление оценки с причиной |
| 3:55–4:30 | Обе роли | Перевод сохраняет историю; отзыв закрывает учебный доступ. Итоговые доказательства CI/backup, текущие ограничения и NO-GO |

Не создавать десятки входов ради дублей; использовать реальные неотозванные сессии. Если время не совпадает с текущей парой, показать честную заранее снятую clock-fixture запись с подписью, не менять production clock. Для живого выступления допускается сократить административную часть до одного действия, не имитировать завершение загрузки.
