## Шаги и результат

1. **Структура — пройдено.** Одно направление содержит группы первого и второго курса; иерархия читается по отступам. Отдельно PostgreSQL проверяет реальное удаление пустых группы/направления/факультета, отказ при связях, запрет STUDENT и чужого вуза, конкурентное удаление и сохранённый аудит.
2. **Размещение — пройдено.** Семестр начинается во вторник; понедельник недоступен для публикации. Разовое занятие выбрано по умолчанию; выбран числитель. Готовая лекция сохраняет две группы, даже если фильтр показывает один курс.
3. **Предпросмотр — пройдено.** До подтверждения видны даты 01/15/29 сентября, время и обе группы. Сервер проверяет конфликты по всем датам. Отдельные сценарии конструктора проверяют исключения, знаменатель и конфликт аудитории; отсутствие ресурсов отклоняется сервером.
4. **Расписание — пройдено.** Мобильный список дней и desktop-таблица показывают одно общее занятие. Во всех четырёх ширинах проверены document и внутренний workspace на горизонтальное переполнение.
5. **Отмена и уведомление — пройдено.** Только одна дата отменена; студент получает уведомление с дисциплиной, датой и временем и открывает своё расписание. PostgreSQL дополнительно подтверждает отсутствие дублей, полный откат при сбое уведомления, отказ IDOR, сохранение уведомления после отзыва и закрытый переход, отмену при занятой строке и гонку с переводом.
6. **Оценки — пройдено.** Две самостоятельные оценки 3 и 5 одной дисциплины находятся в одной карточке; обе роли видят 4 за выбранный период. Отдельная PostgreSQL-проверка с 28 оценками подтверждает независимость среднего от страницы, фильтр дисциплины и пустой период.

## UX-проверка по снимкам

- Сохранены палитра, белые блоки, типографика, верхняя кнопка выхода и нижняя мобильная навигация. Вложенность и курс видны без открытия редактора.
- Список групп и конкретные даты доступны до подтверждения; отмена остаётся в таблице, а не исчезает из истории.
- Длинные названия переносятся в карточках; native select использует сокращённое отображение с полным текстом варианта при раскрытии. Длинные формы требуют вертикальной прокрутки.
- Снимок загрузки уведомления был отклонён: в комплект принимается только кадр после проверки заголовка и текста. Подпись перехода соответствует расписанию.
- По скриншотам не заявляется полное соответствие WCAG. Полный аудит screen reader, контраста всех сочетаний и физического touch-устройства не выполнялся. Проверка семантических ролей и рабочих действий входит в E2E; масштаб браузера сверх проверенных viewport отдельно не исследовался.

## Проверки и границы

Локально: lint/typecheck/build, 22 unit, 88 integration в полном прогоне; после уточнений — 13 целевых проверок конструктора и сквозная PostgreSQL-проверка с конфликтами/правами/предпросмотром очистки. Три целевых Chromium-сценария конструктора и рабочего экрана прошли. Итоговые полные Node, Documentation и VPS CI и точный SHA указываются в Draft PR: исторические результаты main ими не заменяются.

Миграции требуют полного сценария обновления. Действующий VPS не затронут. Очистка — только явный read-only предпросмотр; большой экспорт и ручной merge остаются владельцу. Production NO-GO сохраняется.
