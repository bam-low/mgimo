# Не снятые состояния и ограничения покрытия

[Галерея](README.md) · [Матрица](COVERAGE.md)

| Состояние | Причина и имеющаяся замена |
| --- | --- |
| Выданные регистрацией логин и пароль | Намеренно исключены: реквизиты нельзя публиковать. Сняты форма, ожидание, отказ и повторная подача. |
| Системный выбор файла, Save As и встроенный PDF viewer | Это интерфейс браузера/ОС за пределами canvas страницы. Сняты реальные выбор/сохранение файла в форме, версии и защищённая ссылка; байты скачивания проверены отдельно. |
| Нативный JavaScript confirm замены документа | Playwright обрабатывает реальный диалог, но PNG страницы не включает его окно. [Текст фактически полученного диалога](dialogs.json); сняты форма замены и неизменяемая история. Это не нарисованный модальный макет. |
| Нативная подсказка required/браузерной валидации даты | Снята введённая невозможная дата 31.02.2027; кадр не выдаётся за серверную ошибку. Реальная серверная ошибка неподдерживаемого файла снята отдельно. |
| Отдельное модальное окно подробностей занятия студента | Такого отдельного интерфейса нет: данные показаны внутри карточки. Кадр расписания одновременно покрывает inline-подробности; одинаковый PNG не размножен. |
| Все виды 403/401/409/413/429/503 и транспортные ошибки | Не все превращены в отдельные кадры. Есть отказ прикрепления, закрытый профиль после отзыва, ошибка входа, 404 и ошибка формата. Искусственные подмены ошибок API для галереи не использованы. |
| Исправленное разовое занятие и отдельный экран всех изменений расписания | Есть реальное редактирование сотрудником и отмена в карточке студента; исчерпывающая визуальная история всех вариантов изменения не подготовлена. Отдельный журнал изменений студента не следует подразумевать существующим. |
| Аннулирование оценки, все конфликтные ветви конструктора, пустые справочники | Не выделены отдельными снимками. Есть заполненная/пустая успеваемость, исправление, справочники, общая лекция и её редактор, предпросмотр. Галерея не заменяет функциональные тесты этих ветвей. |
| Другая ОС, Safari/Firefox, экранная клавиатура, screen reader, 200% zoom | В текущем комплекте только настоящий Chromium при 100% и заданных ширинах. Доступность и реальные устройства требуют отдельного прохода. |
| Все сочетания состояния × четырёх ширин | Четыре ширины сняты для основных страниц; редкие состояния преимущественно 360 px. Точная полнота указана в матрице, без заявления о полном декартовом покрытии. |

Это известные границы комплекта, а не перечень обязательных новых функций. Уведомления этапа 7 не добавлялись.
