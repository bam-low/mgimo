Дополнительно через настоящие защищённые API созданы дисциплины, оценки, преподаватель, аудитория, произвольный семестр, исключения и единая лекция для двух групп. Регистрация, отказ, повторная подача, подтверждение, перевод и отзыв выполнены разрешёнными сценариями приложения. Обращения действительно принимались в работу, комментировались, завершались и отклонялись. Для справки сохранены две настоящие неизменяемые версии; скачанный студентом PDF побайтно совпал с загруженным: [безопасный результат проверки](download-check.json). Неподдерживаемый TXT действительно отклонён сервером, старая справка сохранена.

Только в изолированной fixture добавлены четыре вымышленных занятия на 16.11.2026 с аудитом, включая отменённое. Это настоящие записи PostgreSQL. Изображения не заменены статическим HTML, ответы API для съёмки не подменялись.

## Контролируемое время

Внешний тестовый Node-hook управляет часами процесса, Playwright clock — часами браузера. Исходная бизнес-логика и расчёт расписания сохранены. Для текущей пары используется понедельник 16.11.2026, 09:15 по Москве; для перемены — 09:55; для пустого дня — воскресенье 22.11.2026, 10:00. Время фиксируется в каждой записи manifest. Это демонстрация состояний, а не утверждение, что съёмка состоялась в эти календарные дни.

## Форматы

- `viewport`: непосредственный PNG Chromium, 900 px по высоте; некоторые кадры намеренно прокручены к существенной форме/ошибке.
- `full-page`: настоящий `page.screenshot({fullPage:true})`, без изменения размеров контейнеров.
- `full-scroll-stitched`: мобильная оболочка использует внутреннюю прокрутку. Полное содержимое механически собрано Pillow из настоящих последовательных кадров этой области с учётом фактического scrollTop. CSS, DOM и адаптивная компоновка не изменялись; такая склейка не является единым browser fullPage. Закреплённая навигация видна на обычном viewport, не повторяется на каждом фрагменте склейки.
- Миниатюры и контактные листы — уменьшенные копии этих PNG, без дорисовки интерфейса.

SHA256 и фактические размеры каждого исходного PNG находятся в [manifest](manifest.json). Побайтно одинаковые снимки объединены, [алиасы покрытия](coverage-aliases.json) сохраняют смысл соответствующих сценариев. Основные страницы представлены на четырёх ширинах, дополнительные состояния преимущественно на 360 px; матрица не обещает каждое состояние на каждой ширине.

## Секреты и границы

В комплект не входят env, cookies, storageState, HAR, дампы БД, пароли, реквизиты выданных при регистрации аккаунтов, сетевые заголовки и загруженные файлы. Скриншоты страницы с выданными реквизитами намеренно отсутствуют. Все имена и обращения вымышленные; справка имеет маркировку образца. Перед снимком проверялось отсутствие заполненного поля пароля.

Production NO-GO сохранён; локальная TLS/VPS rehearsal не является deploy. Функциональная, юридическая и WCAG-приёмка этим комплектом не объявляются.

## Проверки комплекта

Проверены 118 PNG: декодирование, размеры и SHA256; все 236 адресов исходных изображений и миниатюр доступны. Chromium проверил фильтры ширины/роли и открытие полного изображения в галерее через временный loopback HTTP. Открытие file:// блокируется политикой управляемого браузера этой среды, поэтому именно этот способ здесь не подтверждён; HTML содержит данные внутри файла и не требует API/сервера приложения. Для просмотра без установки доступна также Markdown-галерея непосредственно на GitHub.

Документационный checker и git diff --check пройдены; ZIP проверен на целостность. Приватные значения из локального env не обнаружены среди материалов. Полные test logs, error-context и HAR в архив не включены.
