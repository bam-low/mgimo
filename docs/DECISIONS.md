## Утверждено

| ID | Решение |
| --- | --- |
| A01 | Конкурсный работающий MVP, исключительно вымышленные данные, явная маркировка «концепт, не официальный сервис». |
| A02 | Две роли и интерфейса: студент и сотрудник деканата. |
| A03 | Студент: регистрация/вход, факультет → направление → группа, профиль, расписание сегодня/неделя, оценки/зачёты, заявки/статусы, уведомления. |
| A04 | Сотрудник создаёт и управляет факультетами, направлениями, группами и групповым расписанием; обрабатывает заявки и меняет статус. |
| A05 | Расписание принадлежит группе и доступно студенту через связь с группой, без копирования. |
| A06 | На главной все пары сегодня с временем; текущая выделяется по реальному времени в зоне вуза; прогресс при необходимости; состояния «до пар», «перемена», «все пары закончились», «сегодня пар нет». |
| A07 | Дизайн приоритетен, mobile-first от 360 px; исходное требование Issue #1 — сравнить три авторские концепции без шаблонного AI-dashboard. На этапе Issue #1 выбор отсутствовал; позднейший выбор зафиксирован A15. |
| A08 | Встроенного GPT/ИИ-помощника в MVP нет. |
| A09 | Один вымышленный демонстрационный вуз; несколько вузов учитываются структурно, multi-tenant SaaS не реализуется. |
| A10 | Минимум два студента с различными данными и один сотрудник; серверные права, хеширование паролей и безопасное хранение секретов. |
| A11 | Прототип и все ресурсы доступны из РФ без VPN; конкурсные материалы — отдельная часть работы. |
| A12 | Issue → Codex → тесты/проверки → PR → ручное утверждение владельцем. Автоматический merge запрещён. |
| A13 | Issue #1: только семь документов/инструкций в отдельной ветке через Draft PR, без приложения, зависимостей, UI-кода, инфраструктуры и фиктивных тестов. |
| A14 | Уточнение владельца от 2026-11-04: обязательный конкурсный отчёт включает проблему/сценарии, полный перечень ИИ/IDE/сервисов, ключевые промпты/диалоги, скриншоты удачных/неудачных итераций, объяснение входа/БД/безопасности и ручные этапы. Видео до 5 минут опционально. Начало подачи — 8 ноября 19:00 МСК, итоги — 28 ноября; закрытие подачи не указано. |
