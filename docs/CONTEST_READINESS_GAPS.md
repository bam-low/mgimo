# Конкурсная готовность: отдельные решения владельца

Сверка с известными требованиями [PRD](PRD.md), а не со всеми возможными условиями конкурса. Оригинальное актуальное ТЗ/форма подачи и дедлайн закрытия не подтверждены. Это список решений, **не разрешение новых функций**. Функциональный scope MVP заморожен; VPS maintenance не меняет приложение.

| Область | Подтверждённый статус / пробел | Решение владельца |
| --- | --- | --- |
| URL и РФ без VPN | В PRD доступность из РФ обязательна; реальный стенд/загрузка всех ресурсов с двух сетей не проверены. CI не заменяет эту проверку | После получения подписанного RC отдельно разрешить покупку/защищённый запуск; определить, как жюри получает доступ через закрытый gate |
| Два студента и STAFF | Есть вымышленные seed accounts и E2E двух разных студентов; безопасная выдача реквизитов жюри и доступ на целевой площадке ещё не подтверждены | Согласовать частный способ выдачи, подготовить финальный проверенный demo roster; секреты не в отчёте/Issues |
| Финальный конкурсный отчёт | В репозитории есть [структура](audit/stage-8-2026-11-14/FINAL_REPORT_OUTLINE.md), аудит, AI_LOG и галереи; наличие окончательного принятого конкурсного файла не подтверждено | Утвердить формат/объём и собрать финальный отчёт: проблема, сценарии, архитектура/безопасность, ИИ-инструменты/IDE/сервисы, промпты/диалоги, успешные и неуспешные итерации, вклад человека |
| Условия подачи | PRD знает начало8ноября19:00МСК и итоги28ноября; время закрытия и текущий формат не установлены. 21ноября — внутренний срок владельца | Предоставить/сверить актуальные правила и точный submission deadline; не выводить его из даты итогов |
| Дизайн и доступность | [Аудит](audit/stage-8-2026-11-14/FINDINGS.md) нашёл UX-01 на360 при root font-size200%; физические устройства/screenreader/полный WCAG не проверены. Пиксельная актуальная Figma-приёмка агентом не подтверждена | Определить обязательность исправления UX-01 и ручного device review до демонстрации; это отдельный scope, CSS сейчас не меняется |
| Обозначение концепта | Исторический PRD требует «концепт, не официальный сервис», позднейшее решение владельца/mergedPR53 удалило служебную подпись интерфейса | Подтвердить, достаточно ли пояснения в конкурсном отчёте; без разрешения подпись в UI не возвращать. Маркировку вымышленных справок сохранить |
| Релизный комплект | До зелёного merge-main, отдельно разрешённого export, проверки скачанного комплекта, подписи и двух долговечных копий передача RC не завершена | Review нового Draft PR → ручной merge → три main CI → квота/разрешение export → локальная подпись/архив. [Порядок](VPS_RC_HANDOFF.md) |
| Видео | По известному PRD видео до5мин опционально; [сценарий](audit/stage-8-2026-11-14/DEMO.md) подготовлен, окончательная запись не подтверждена | Решить, нужна ли запись3–5мин и кто её делает; не объявлять обязательной без нового ТЗ |

Подтверждённых отсутствующих обязательных пользовательских вертикалей по текущему PRD при этой сверке не установлено: регистрация/прикрепление, расписание, успеваемость, заявки/справки и STUDENT-уведомления реализованы и проверяются CI. Это не доказательство соответствия неизвестным дополнительным условиям конкурса. STAFF-уведомления, email/SMS/push/ИИ, настоящие документы и PDF generation были явно исключены владельцем; не считать их дефектами и не начинать без отдельного решения.

Исторические security counts аудита df58c104 не являются текущими: tools HIGH исправлялись в #54, актуальный scan — только exact-build reports будущей поставки. Прежняя матрица/110PNG сохраняются с исходным baseline. Реальные host/тариф/домен/доступ РФ остаются серверными условиями, не поводом покупать VPS до завершения передачи сборки.
