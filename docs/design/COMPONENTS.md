## Матрица времени для главной

| Условие в зоне вуза | Представление | Прогресс |
| --- | --- | --- |
| До первой пары, занятия есть | Все пары со временем + «до пар» | Нет фиктивной текущей пары |
| Реально активная пара | Все пары; активная выделена текстом/формой и визуально | 0–100% и текстовый эквивалент |
| Между парами | Все пары + «перемена» | Нет фиктивной текущей пары |
| Последняя пара завершилась | Все пары + «все пары закончились» | Нет фиктивной текущей пары |
| В этот день нет занятий | «Занятий нет» | Нет текущей пары |

Точное включение границ интервала [начало, конец), синхронизация часов, обработка пересечений и интервалы обновления остаются техническими предложениями/вопросами из архитектуры, а не новыми утверждёнными решениями дизайна. Будущие проверки должны охватить начало/конец, перемену, смену дня и отличающуюся зону устройства. Обновление не должно подменяться статичной демонстрационной «активной парой».

### Поведение, которое нельзя изменить редизайном

- Сохранить текущий контракт `[start,end)`, university IANA day, serverNow/монотонный elapsed time, second tick/30s polling/focus/day rollover и stale response guard из SCHEDULE. Motion tokens описывают визуализацию, не разрешают менять часовой расчёт или показывать stale private data.
- Обработка API denied/validation/conflict/outage не подменяется декоративными success states. Deactivation/отзыв/перевод сохраняют историю и действующие серверные guards.
- Loading/empty/error показывают фактическое состояние; назначение grade/request/notification модуля в PRD не означает наличия данных уже сейчас.
- Точные hover/focus/selection цвета, плотность, размеры и responsive состояния требуют source styles/исправленных fonts и owner review, без пиксельного «восстановления» недоступных Figma-слоёв.
