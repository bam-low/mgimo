## При передаче владельцем

Сохранить именно предоставленные оригиналы в пригодном формате, проверить открытие и безопасное содержимое (особенно SVG), соответствие решению и отсутствие реальных университетских логотипов/персональных данных. Не называть файл финальным без явного утверждения. Сведения о происхождении не считать лицензией.

Для каждого файла заполнить: фактический путь и рабочую ссылку, источник/проверенный архив, дату получения и отдельно дату создания (если известна), автора/оператора и ИИ-инструмент/модель (если известны), формат, размеры и разрешение (для вектора — параметры экспорта), разрешение/лицензию, связь с решением владельца, статус reference / selected-direction / approved-final, доступность редактируемого исходника. Неизвестное оставлять TBD, статус ASSET_NOT_PROVIDED снимать только после реального получения.

Владельцу ещё необходимо предоставить исходные изображения либо доступный проверенный архив; отдельным решением — финальный вектор B, версии и охранное поле. До передачи точная визуальная сверка заблокирована, документация известных решений допустима.
