## Визуальная концепция и статусы

Academic Editorial 2.0 соединяет интеллектуальную редакционную типографику со светлыми мягкими поверхностями; иллюстративные и цветные акценты ограничены. Бордовый акцент не должен превращать страницу в тяжёлое сплошное полотно. Приоритет — сегодняшний учебный день и понятные действия, без шаблонного dashboard из декоративных счётчиков. Роли используют одну идентичность; сотруднику нужна более плотная рабочая композиция без потери читаемости.

## Типографика: намерение, исходники и кириллица

Newsreader — подтверждённое display-намерение, Plus Jakarta Sans — body/label. По сообщению владельца в Issue #31 отдельные Figma text layers сейчас Liberation Serif, часть блоков смещена. Это **сообщение источника**, не повторно полученная структура Figma. Liberation Serif не становится утверждённой заменой; нельзя лечить дефектные переносы случайными margin/absolute positioning. До исправленной типографики эталон — композиционный, не pixel-perfect для надписей.

06.11.2026 проверены официальные regular variable TTF из Google Fonts на revision `86aced91de05cd4f96a06838124cca45be337b2b`. Файлы скачивались только во временный каталог для исследования, в приложение/репозиторий не устанавливались. SIL OFL 1.1 допускает распространение/embedding с соблюдением условий и сохранением лицензии; это не доказательство лицензий иллюстраций/иконок или утверждение конкретной поставки шрифтов.

Метод: установленный в среде fontTools/TTFont, объединение ключей всех Unicode cmap tables; проверен набор U+0410–U+044F плюс Ё U+0401/ё U+0451. Оба исследованных файла не покрывают этот набор. Наличие `cyrillic-ext` в metadata Plus Jakarta Sans не заменяет проверку реальных glyph mappings. Это вывод **о конкретных файлах с указанными hashes**, не утверждение о всех возможных будущих сборках семейств. Доступные variable axes не задают выбранные веса/optical size UI.

**OPEN / gate перед UI-реализацией:** получить легальные кириллические поставки заявленных гарнитур либо отдельно утвердить кириллическую альтернативу/fallback и её применение к display/body/label. Автоматического выбора новой гарнитуры нет. Затем проверить русский/латиницу/цифры, Ё/ё, длинные названия групп/дисциплин, смешанный текст, загрузку/fallback и переносы на 360/390/1280; хранение assets/лицензии локально и работа из РФ требуют отдельной проверки. До решения на этих TTF нельзя обещать Newsreader/Plus Jakarta Sans для русских надписей.

## Контракты для будущей реализации

- [TOKENS](TOKENS.md) фиксирует ровно подтверждённую базу; неподтверждённое TBD/PROPOSED. Семантические text/border/state пары не выводятся автоматически из brand цветов.
- [COMPONENTS](COMPONENTS.md) описывает содержание/состояния/плотность/доступность, без API/React props и реализации. [RESPONSIVE](RESPONSIVE.md) разделяет контрольные ширины и открытые breakpoints; staff mobile — только предложение.
- Сохранить живую университетскую дату, все пары дня, serverNow/монотонное elapsed time, обновление/late-response guard, no-store/права и весь synthetic-only UX. Визуальная «выбранная» ячейка inspector не означает реально текущую пару студента.
- PENDING/REJECTED, отозванная/неактивная группа, session revoked и User inactive не получают учебный доступ; профиль/история и A31/A32 сохраняются. Активный пункт навигации или цвет не дают серверных прав.
- Формы сохраняют strict validation, safe conflict, error/busy/success, подтверждение деактивации/отмены/удаления и audit. Не вводить drag/drop, recurrence или новый API как побочный эффект сетки.

## Приёмка handoff и следующей UI-Issue

Этот Draft PR готов для ревью документации с явными отсутствующими входами. **Полная Figma-сверка и готовность русской типографики не объявляются завершёнными.** Допустимость продолжения по неполным exports/типографике решает владелец; недостающие числа остаются TBD, приложение не меняется.

После ручного принятия handoff — отдельная UI-Issue, без автоматического создания/начала реализации сейчас. В её приёмку включить: snapshots 360/390/1280 и предложенный staff mobile; пять временных состояний и midnight/IANA/внешнюю зону браузера; живой прогресс; keyboard/focus/labels/контраст/масштаб/reduced motion; реальные пустые/ошибочные/загрузочные состояния и длинную кириллицу; regression auth/registration/approval/reject/retry/transfer/revoke/schedule/staff CRUD; standalone/Functions/VPS runtime isolation. Screenshot сравнение не использовать для закрепления геометрии слетевших текстовых слоёв.
