Новые преобразования дат — только presentation layer: дата календаря не становится UTC-временем занятия. Сервер по-прежнему интерпретирует локальные ISO day/HH:mm в IANA зоне вуза, проверяет интервалы и полномочия. Невалидный/неполный текст не преобразуется в угадываемую дату; существующий диапазон2000–2100 и точность минут сохранены. Конкретный вид системного picker зависит от браузера/ОС; поле приложения не показывает AM/PM или неоднозначный slash-date. Ввод с клавиатуры остаётся доступным, если showPicker не поддерживается.

## Прокрутка и клавиатура

[Workspace](../../src/app/workspace.tsx) получает фактическую visualViewport.height при resize; viewport meta запрашивает resizes-content у поддерживающих браузеров. Resize повторно показывает активное поле в собственном scrollport. После выбора карточки focus переходит к title; приложение не скрывает поле под nav. Никаких глобальных body overflow:hidden для маскировки ширины.

Playwright проверяет настоящий scroll и уменьшение viewport до420px при фокусе. Это **модель изменения доступной высоты**, не эмуляция конкретной iOS/Android клавиатуры. Реальные устройства, browser chrome/pan, safe-area на iPhone и IME остаются ручной проверкой владельца. Text200% проверяется отдельно на360/1280. Desktop сохраняет обычную прокрутку документа.

## Evidence и пределы

[Сравнение baseline/после, viewport/full-page/end/inspector](../screenshots/issue-34/review-2026-11-07/README.md). Старые PNG не заменены. На mobile full-page документа теперь совпадает с app viewport: длинное содержимое прокручивается внутри Workspace. Поэтому приложены отдельные реальные кадры конца/календаря/inspector; длинный screenshot не считается доказательством отсутствия overlap. CSS не меняется специально ради screenshot, изображения не склеиваются и не генерируются.

Обычные screenshots идут из действующего приложения/реальной отдельной PostgreSQL. Новый state-тест отдельно использует настоящие seed-занятия и контролируемый serverNow в test-only ответе для before/current/break/after и живого перехода current→break. Он не меняет часы сервера, данные или production; не подменяет серверные auth/интеграционные проверки. Empty/multiple days также проверяются на настоящем API существующего seed.

Улучшение конкурсного наполнения — [отдельное PROPOSED предложение](DEMO_CONTENT_PROPOSAL.md), без выполнения. Production NO-GO сохраняется; известные vendor HIGH и реальные host/cloud/РФ gates не закрываются UI-ревью. Финальное визуальное утверждение, полный screenreader/WCAG и реальные мобильные устройства — вручную владельцем. Без merge/auto-merge/deploy/облачных ресурсов.
