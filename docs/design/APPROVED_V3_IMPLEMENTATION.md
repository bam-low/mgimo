## Утверждённые решения (APPROVED)

1. **Типографика — замена первоначальной пары:** `typography.display.family = Literata`; `typography.body.family = Onest`; `typography.label.family = Onest`. Ранее указанная в styleboard пара Newsreader / Plus Jakarta Sans сохраняется **как исторический референс**, но больше **не является целевым набором шрифтов для реализации**. Причина — отсутствие русских глифов в конкретных исследованных поставках. Не использовать Liberation Serif из Figma как целевой font-family.
2. **Цвета без изменений:** `#753A4A` (primary), `#25283B` (secondary), `#E7E0F2` (tertiary), `#F7F4EE` (neutral).
3. **Mobile STAFF:** нет отдельного утверждённого макета; **Codex уполномочен спроектировать адаптацию** на 360px+ на основе desktop, сохраняя управление группами и занятиями, доступность и читаемость. Это не разрешение добавлять новые операции.
4. **Иконки и иллюстрации:** владелец подтверждает, что элементы Figma сгенерированы и разрешает использовать их в MVP. Это разрешение владельца на использование переданных им материалов, **но не подтверждение сторонних лицензий**. Сохранять реальные SVG/PNG из Figma как локальные ассеты, provenance, не использовать временные Figma asset URLs в runtime. Не подменять их похожими стоковыми изображениями. Отдельное утверждение финального логотипа по-прежнему требуется.
5. **Второстепенные дизайн-детали:** Codex вправе самостоятельно определить недостающие значения spacing/radius/shadow/breakpoints, typography scale/weights, semantic state colors, icon sizes и motion в рамках палитры и стиля, с проверкой WCAG AA, responsive и фиксацией решений в TOKENS/DECISIONS. При существенном отклонении от Figma, смене продукта/доступов — вынести на ревью.
6. **Не менять продуктовые границы:** рабочее расписание и серверные права доступа сохраняются; не делать фальшивые оценки, заявки, уведомления, CMS/интеграции/автоматическое планирование только потому, что они нарисованы на Figma.

## Обязательные проверки перед/при UI-реализации

- **Шрифты:** проверить реальные локальные файлы Literata и Onest через Unicode cmap: А–Я, а–я, Ё/ё, цифры, латиница, длинные названия, weights/italic. Сохранить лицензии (при соответствующей лицензии OFL) и локальную загрузку, без зависимости от Google Fonts CDN для пользователей из РФ. Если подходящих файлов нет, остановиться и согласовать альтернативу; **не подменять утверждённую пару молча**.
- **Адаптивность:** 360, 390, 1280 CSS px плюс промежуточные ширины; no horizontal page overflow, keyboard focus, contrast AA, reduced motion. Мобильный STAFF — самостоятельная адаптация.
- **Функции:** активная пара и progress по университетской IANA timezone, все занятия текущей группы, разграничение ролей и данных, существующие API и тесты без регрессии.
- **Источник истины:** Figma задаёт композицию/визуальный характер, а PRD/Architecture/Decisions/Schedule — доступные действия. Не пытаться пиксельно повторить текстовые переносы слоёв, в которых был Liberation Serif.
- **Демонстрация:** сравнимые реальные скриншоты до/после, тесты UI/E2E и документация README для разработчика, другой нейросети и жюри.
- **Production:** NO-GO до отдельного security/deployment gate; не покупать VPS и не деплоить.

**Режим работы:** эта запись — документационное решение, не разрешение на прямые изменения main. UI-реализация должна идти в отдельной утверждённой Issue → Draft PR → проверки → ручной merge владельца.
