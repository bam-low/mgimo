## Контекст для продолжения

- Локальный запуск: Docker Desktop → `docker start campus-local-demo` → `node node_modules/next/dist/bin/next dev --hostname 127.0.0.1` → http://localhost:3000. Логины `student1@example.test`, `student2@example.test`, `staff@example.test`, пароли в `.env.local` (`DEMO_*_PASSWORD`). Если вход «молча» не проходит — dev-сервер сломался (лог `.next/dev/logs/next-development.log`, «Jest worker … /api/auth»): остановить процесс на :3000, `rm -rf .next/dev`, запустить заново.
- Стили: старые `globals.css`, `student-polish.css`, `ux-polish.css` обёрнуты в `@layer legacy`; новый `src/app/design.css` без слоя всегда побеждает. `!important` внутри legacy перебить нельзя — такие места правятся в самом legacy-файле.
- Логотип: `public/brand/*.svg`, генератор — скрипт в scratchpad (`logo/gen.mjs`, контуры Literata через opentype.js, начертание 400 + обводка). Favicon: `src/app/icon.svg`.
- Контракты E2E (проверять после правок на 360/390/768/1280): «Выйти» по центру строки логотипа (|Δy| < 2), кнопка ≥ 44 px, без горизонтального скролла, на телефоне `.workspace-scroll` заканчивается над `.campus-nav`, контраст `.eyebrow, .badge, .lesson h3, .lesson-time, .day-status h2, .current-times, .timetable-lesson, .campus-nav a` ≥ 4.5, фокус `.campus-nav a` — `outline-style: solid`. Тексты кнопок «Проверить изменения» / «Подтвердить и сохранить» и подписи полей не менять (на них держатся E2E). Фильтры заявок у сотрудника должны оставаться раскрытыми, формы создания структуры — видимыми.
- Перед выпуском: lint, typecheck, vitest; полный прогон E2E и репетиции — при сборке релиза в Codespaces (`docs/release/RELEASE_UX_EFFECT_2026-11.md`).
