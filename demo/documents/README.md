# Вымышленные образцы документов

PDF, PNG и JPG содержат только специально вымышленные сведения и видимую маркировку «Образец / Не является официальным документом». Это один синтетический макет, без настоящих подписей, печатей и юридической силы.

Файлы предназначены для ручной загрузки сотрудником в локальном демо и для проверки настоящих байтов в тестах. Они находятся вне `public/`, не выдаются по публичному URL и не входят в runtime как тестовые fixtures. Приложение не генерирует PDF и не подписывает документы.

Макет подготовлен для проекта программно из текста и геометрических элементов; использованы системный DejaVu Sans, sharp и pdf-lib. Проверка сотрудником всех страниц и демонстрационной маркировки обязательна и для этих образцов.
